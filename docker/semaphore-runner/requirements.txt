# docker/semaphore-runner/requirements.txt — the Python packages the control image adds to the Semaphore base's
# ansible venv: the whole set, one exact pin each. The Dockerfile installs it with `--no-deps` (nothing this file
# does not name can be installed or moved) and then runs `pip check` (the build fails if the set is incomplete or
# conflicts with the base). Produced by docker/README.md § Refreshing a pin — the difference between `pip freeze`
# in the bare base's venv and `pip freeze` after installing flask, fastapi, uvicorn, paramiko and PyYAML — and
# never edited by hand without that rebuild. paramiko and PyYAML come with the base; the Dockerfile's import line
# fails the build if a new base drops either. gui/requirements.txt and api/requirements.txt stay the development
# floors; tests/unit/test_image_pins.py holds that every package they name is here or in the base.
# Hash pins (--require-hashes) are the next rung, not this one: they need every wheel's hash for each platform the
# publish workflow can build, and nothing in the repo produces them yet.
